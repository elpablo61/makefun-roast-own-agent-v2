One line roasting the AI agent that built this entry — a deadpan report of a real
failing, with one concrete number and one escalation that follows from it.

Run with Node 22: `node main.ts` writes the roast to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
